# ToDoApp

ASP.NET Core を学習するための ToDo 管理アプリです。

## 使用している技術

- C#
- ASP.NET Core MVC
- .NET 10
- Visual Studio

## 現在の状態

ASP.NET Core MVC の初期プロジェクトを作成した状態です。
これから、ToDo の登録、一覧表示、完了、削除を少しずつ追加します。

## 実行方法

1. .NET 10 SDK をインストールします。
2. このリポジトリを取得します。
3. リポジトリのルートで、次のコマンドを実行します。

```powershell
dotnet run --project .\WebApplication\WebApplication.csproj
```

4. コマンドに表示された URL をブラウザーで開きます。

## 学習予定

1. MVC の役割を理解する
2. ToDo のモデルを作成する
3. ToDo の一覧を表示する
4. ToDo を登録する
5. ToDo を完了にする
6. ToDo を削除する
7. データベースに保存する
8. 入力チェックを追加する

複雑な機能を一度に追加せず、動作を確認しながら基本的なコードで作成します。
