| 項目 | 内容 |
|---|---|
| アプリケーション名 | ToDoApp |

| 対象フレームワーク | .NET 10 |

## 2. アプリケーションの目的

ToDoApp は、やるべきことを登録して一覧で確認するための Web アプリケーションです。

このアプリケーションでは、次の基本を学習します。

- Model、View、Controller の役割
- URL と Controller アクションの関係
- HTML フォームから値を受け取る方法
- 入力値を検証する方法
- 一覧表示、登録、編集、完了、削除の基本処理
- データを保存する方法

## 3. 開発方針

- 初学者が処理の流れを追いやすい、平易なコードにする
- 1つの処理を複雑なメソッドにまとめすぎない
- まず動くものを作り、その後にデータベースなどを追加する
- 既存の ASP.NET Core MVC の構成を利用する
- 必要になるまで新しいライブラリを追加しない
- 画面、Controller、Model の役割を分ける

## 6. データ設計

## 6.1 ToDo モデル

クラス名は `TodoItem` とします。

| プロパティ | 型 | 必須 | 内容 |
|---|---|---|---|
| Id | int | 必須 | ToDo を識別する番号 |
| Title | string | 必須 | ToDo のタイトル |
| IsCompleted | bool | 必須 | 完了しているかどうか |
| CreatedAt | DateTime | 必須 | 作成日時 |
| CompletedAt | DateTime? | 任意 | 完了日時 |

### 初期値

| プロパティ | 初期値 |
|---|---|
| Id | 連番で設定 |
| Title | 空文字ではない入力値 |
| IsCompleted | false |
| CreatedAt | 登録時の日時 |
| CompletedAt | null |

## 6.2 入力ルール

- タイトルは必須
- タイトルは 1 文字以上 100 文字以下
- 前後の空白は取り除く
- 空白だけのタイトルは登録できない

## 7. MVC の構成

```text
WebApplication/
├─ Controllers/
│  └─ HomeController.cs
├─ Models/
│  ├─ ErrorViewModel.cs
│  └─ TodoItem.cs
├─ Services/
│  └─ TodoService.cs
├─ Views/
│  ├─ Home/
│  │  ├─ Index.cshtml
│  │  └─ Edit.cshtml
│  └─ Shared/
└─ Program.cs
```

### 各部分の役割

#### Model

ToDo のデータを表します。

#### View

ブラウザーに表示する HTML を作成します。

#### Controller

ブラウザーからの要求を受け取り、Model と View をつなぎます。

#### Service

ToDo の登録、取得、更新、削除を担当します。
Controller にすべての処理を書かないために使用します。

#### Program.cs

アプリケーションの起動設定と、Service の登録を行います。

## 8. URL と処理の設計

| HTTP メソッド | URL | Controller アクション | 内容 |
|---|---|---|---|
| GET | `/` | `Index()` | ToDo 一覧を表示 |
| POST | `/Home/Create` | `Create()` | ToDo を登録 |
| GET | `/Home/Edit/{id}` | `Edit(int id)` | 編集画面を表示 |
| POST | `/Home/Edit` | `Edit(TodoItem todo)` | ToDo を更新 |
| POST | `/Home/Complete` | `Complete(int id)` | ToDo を完了 |
| POST | `/Home/Delete` | `Delete(int id)` | ToDo を削除 |

## 9. 処理の流れ

## 9.1 一覧表示

1. ブラウザーが `/` にアクセスする
2. `HomeController.Index()` が呼び出される
3. `TodoService` から ToDo 一覧を取得する
4. Controller が一覧を View に渡す
5. `Index.cshtml` が HTML を作成する
6. ブラウザーに一覧が表示される

## 9.2 ToDo 登録

1. ユーザーが入力欄にタイトルを入力する
2. 登録フォームを送信する
3. `HomeController.Create()` が呼び出される
4. タイトルの入力チェックを行う
5. 入力が正しければ `TodoService` に登録を依頼する
6. ToDo 一覧画面へ戻る
7. 入力が正しくなければ、エラーメッセージを表示する

## 9.3 ToDo 完了

1. ユーザーが完了ボタンを押す
2. ToDo の ID を Controller に送信する
3. `TodoService` が該当する ToDo を探す
4. `IsCompleted` を `true` にする
5. `CompletedAt` に現在日時を設定する
6. ToDo 一覧画面へ戻る

## 9.4 ToDo 削除

1. ユーザーが削除ボタンを押す
2. ToDo の ID を Controller に送信する
3. `TodoService` が該当する ToDo を探す
4. 該当する ToDo を削除する
5. ToDo 一覧画面へ戻る

## 10. データ保存方法

## 10.1 第1段階：メモリ上に保存

最初は `TodoService` の中に `List<TodoItem>` を用意します。

この方式では、アプリケーションを停止するとデータが消えます。
ただし、データベースを使わずに MVC の基本処理を学べます。

### 第1段階の目的

- Model の作成
- Controller から Service を呼び出す方法
- フォームの送信
- 一覧表示
- 登録、更新、削除

## 10.2 第2段階：SQLite に保存

第1段階が完成した後、Entity Framework Core と SQLite を使用します。

この段階では、アプリケーションを停止しても ToDo が残るようにします。

### 第2段階で追加するもの

- Entity Framework Core
- SQLite データベース
- `TodoDbContext`
- データベースの作成
- データベースからの取得と保存

## 11. エラー処理

- 存在しない ID が指定された場合は、一覧画面へ戻す
- タイトルが空の場合は、画面にエラーを表示する
- タイトルが 100 文字を超える場合は、登録しない
- 予期しないエラーは、既存の Error 画面で表示する

## 12. セキュリティの基本

- フォーム送信には Razor の antiforgery トークンを使用する
- 入力値をそのまま HTML として出力しない
- 削除、完了、更新は POST で実行する
- ユーザー認証は後の段階で追加する

## 13. 実装手順

以下の順番で、1段階ずつ実装します。

### 第1段階：Model

1. `Models/TodoItem.cs` を作成する
2. `Title` に入力ルールを設定する
3. ビルドする

### 第2段階：Service

1. `Services/TodoService.cs` を作成する
2. ToDo の一覧取得処理を作成する
3. 登録、更新、完了、削除処理を作成する
4. `Program.cs` に Service を登録する

### 第3段階：一覧表示と登録

1. `HomeController` に ToDo 一覧処理を追加する
2. `Index.cshtml` を ToDo 一覧画面に変更する
3. 登録フォームを追加する
4. 入力エラーを表示する

### 第4段階：完了と削除

1. 完了処理を追加する
2. 削除処理を追加する
3. 各処理を POST にする
4. 動作を確認する

### 第5段階：編集

1. 編集画面を作成する
2. 編集画面を表示する処理を作成する
3. 編集内容を保存する処理を作成する
4. 入力チェックを追加する

### 第6段階：SQLite

1. Entity Framework Core のパッケージを追加する
2. `TodoDbContext` を作成する
3. `TodoService` をデータベース対応に変更する
4. データベースを作成する
5. アプリケーションを再起動してもデータが残ることを確認する
